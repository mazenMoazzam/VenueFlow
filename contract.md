## Event planner tool

- Deployment
- User accounts
  - Users can create events and add other users to event who can also make edits
- Event planning interface
  - Can edit description, dates, location, expected attendance
  - Visual floor planner interface, can input venue dimensions and click/drag to add/move tables, stages, entrances/exits, chairs, etc.
  - Create budget, add categories of expenses, track projected/actual expenses/revenue (e.g. from tickets) over time, some way to compare different expense/revenue projections
  - Create todo list, can assign tasks to others, can set deadlines for tasks, can see tasks laid out by deadline
  - Create event schedule for attendees and staff
  - Record decisions made (e.g. staff hiring, food, etc)
- Optional: Incorporate external APIs (e.g. Ticketmaster) if needed
